# Проект: исследование качества сервиса «Яндекс.Самокат» (web + mobile + API)

Репозиторий содержит тестовую документацию и результаты комплексного ручного
тестирования учебного стенда сервиса аренды самокатов.

## Описание проекта
Сервис состоит из трёх компонентов: веб-приложение (оформление и статус заказа),
мобильное приложение курьера (Android) и бэкенд (REST API + PostgreSQL).
В ходе проекта система проверялась на соответствие требованиям и API-контракту:
от валидации полей форм до статус-кодов ответов, состояния базы данных и
серверных логов.

## Исследуемые данные
- Требования: 3 документа (веб-приложение, мобильное приложение, бэкенд)
  и API-документация (apidoc);
- База данных PostgreSQL: таблицы `Couriers` и `Orders` (флаги
  `cancelled / finished / inDelivery`, вычисляемый статус заказа);
- Серверные логи `error.log` (чтение по SSH);
- Тестовые данные: классы эквивалентности и граничные значения для 8 полей
  веб-форм, 10 эндпоинтов API, сценарии мобильного приложения;
- Результаты: 350+ проверок чек-листов, 30 тест-кейсов, 80 баг-репортов.

## Цели и основные пункты исследования
1. **Веб-формы:** проверить ограничения полей (длины, наборы символов,
   обязательность) — выявлены отсутствие лимитов и потеря данных заказа.
2. **API:** сверить статус-коды и тела ответов с контрактом — обнаружено
   отсутствие серверной валидации (201 вместо 400), неработающая отмена заказа,
   некорректное логирование (500 в логах вместо 4xx/409).
3. **База данных:** проверить маппинг полей, хеширование пароля, уникальность
   логинов, каскадные удаления — подтверждены дефекты отмены и каскадного
   удаления.
4. **Мобильное приложение:** потоки принятия/завершения заказа, сортировки,
   push-уведомления, офлайн-сценарии — 16 дефектов.
5. **Окружения:** кросс-браузерность (Yandex Browser, Chrome, Firefox)
   и разрешения 1280×720 / 1920×1080.

## Библиотеки и инструменты
- **Postman** — коллекции запросов к REST API, переменные окружения;
- **PostgreSQL / psql** — SQL-запросы для верификации данных
  (SELECT, JOIN, GROUP BY, HAVING, CASE);
- **Chrome DevTools** — анализ сетевых запросов и разметки;
- **Android Studio (эмулятор, Android 9.0)** — тестирование мобильного приложения;
- **OpenSSH (tail, grep)** — чтение и анализ серверных логов.
